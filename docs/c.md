# ROLE
你是我的联合创作者。当前对话即将关闭，你需要生成一份 **“创作状态快照（Creative State Snapshot）”** ，供下一个新对话窗口的LLM读取，使其能无缝接续当前进度，无需追问任何前置信息。

# INPUT
我们迄今为止的完整对话历史，以及最新创作出的故事片段。

# TASK
请按以下五个刚性模块整理状态，**禁止添加任何无关的抒情或评价**：

## [MODULE 1: 物理现实（硬锚点）]
记录所有已经发生、不可撤销的剧情事实。仅限“物理动作”和“公开对话”，格式为有序列表。
- 例：1. 林薇把信塞进了烤箱。2. 陈默当着她的面撕掉了车票。

## [MODULE 2: 人物内部状态（软变量）]
记录每个主要角色**当前**的：
- 公开立场（他对别人说了什么）
- 隐藏欲望（他真正想要但没说出口的）
- 近期情绪峰值（最近一次强烈情绪是由哪件事触发的）
格式：[角色名]：公开/隐藏/情绪锚点

## [MODULE 3: 未落地的伏笔与道具清单（触发器）]
列出所有已被引入但尚未回收、或尚未改变人物处境的元素：
- 人物承诺（某人对某人承诺过什么还没兑现）
- 关键道具（目前谁持有某物，其真正用途尚未揭示）
- 未接听的电话/未拆封的信件等

## [MODULE 4: 下一段的强制起点（硬约束）]
明确指出下一段续写**必须从哪一个具体的物理动作或对话开始**，防止新LLM自由跳转。
- 格式：下一句必须是“[具体动作或台词]”

## [MODULE 5: 当前叙事语气样本（风格锚）]
摘录最近一段约50-100字的原文，作为新LLM模仿语气和节奏的唯一样本。

# NEGATIVE CONSTRAINTS
1. 严禁使用“故事讲述了...”等元叙述语。
2. 严禁压缩或转述人物对话为间接引语。对话必须原样保留在Module 1中。
3. 严禁对伏笔进行“解释”或“暗示解谜”，仅做记录。
